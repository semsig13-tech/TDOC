# Область применения

Настоящие методические рекомендации распространяются на следующие продукты:
- TER_Rec15_Smart1_R7;
- TER_Rec15(25)Al1_L5M;
- TER_Rec35_Smart1_Tie7;
- TER_Rec35_Smart1_Sub7;
- TER_VCB15_LD8 (Shell2)\_SRF2;
- TER_VCB15_LD8 (Shell2)\_SRD2;
- TER_VCB15_LD8 (Shell2)\_SF2;
- TER_VCB15_HD1_3CS_6VS04 (6VS_3CAS);
- TER_VCB15_Shell2_3CS_6VS04 (6VS_3CAS);
- TER_VCB15_MD1_3CS_6VS04;
- TER_OVCB35_Smart_7C (7CS/1C/9CS)

Рекомендации распространяются на модули управления CM_15_4(5/5С/6) модификацией (220_1) и выше.

Для получения актуальной версии встроенного ПО (далее - ВПО) и пользовательского ПО (TELARM Lite, Section Tool) необходимо:
1.     Открыть актуальную версию документа Совместимость версий продуктов TEL ==[TER_SW_Version_Control](null)==
2.     Зайти в раздел нужного продукта;
3.     Определить актуальную версию встроенного ПО, исходя из аппаратной части модуля управления (см. [[#Определение аппаратной части модуля управления]]), и совместимые с ней версии пользовательского программного обеспечения - TELARM Lite и Section Tool;
4.     Скачать нужные версии ПО по ссылке ==[Программное обеспечение](null)==.

# Подготовка к обновлению ПО
## Подать оперативное питание на CM_15

Подайте оперативное питание на все модули управления от сети переменного тока или ТСН. Разъемы питания указаны в таблице [[Реклоузер#^Power-connector|Разъемы питания у модулей управления]].

Разъемы питания у модулей управления: ^Power-connector

| Модуль управления | Разъемы питания |
| ----------------- | --------------- |
| CM_15_4           | X2, X5          |
| CM_15_5           | X4, X7          |
| CM_15_6           | X2, X5, X8, X11 |
| СМ_15_5С          | S2, D3          |


> **Примечание:**
> Обновлять ПО CM_15 при питании только от батареи запрещено!

## Установить соединение с TELARM Lite

В обозревателе баз фидеров выбрать соответствующий реклоузер (выключатель), затем в области «Подключение к устройству» на главном экране программы необходимо выбрать интерфейс подключения (Ethernet или Wi-Fi), IP-адрес устройства, а также ввести пароль (по умолчанию 444444).

По умолчанию IP-адрес:
- для Wi-Fi: 192.168.100.11;
- для Ethernet: 192.168.102.11.
